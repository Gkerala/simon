# 따라하며 누르기

북두칠성 모양으로 놓인 7개의 별(버튼)이 빛나는 순서를 기억했다가 그대로 누르는 기억력 게임입니다. (Simon Says 방식)

**플레이:** https://gkerala.github.io/simon/

## 실행 방법

- 위 링크로 바로 플레이하거나,
- 저장소를 내려받아 `index.html`을 Chrome 또는 Whale에서 열면 됩니다. 서버나 설치가 필요 없습니다.

## 게임 규칙

1. 빨간색 **START** 버튼을 누르면 Stage 1이 시작됩니다.
2. 컴퓨터가 스테이지 번호만큼 별을 무작위 순서로 빛냅니다. (Stage N → N개, 같은 별이 연속으로 나올 수 있음)
3. 시연이 끝나고 화면에 **START** 문구가 뜨면 제한시간이 시작됩니다. 같은 순서로 별을 클릭하세요.
4. 모두 맞히면 **STAGE CLEAR** 후 1.5초 뒤 다음 스테이지로 넘어갑니다. 스테이지 제한은 없습니다.
5. 다른 별을 누르거나 시간이 다 되면 **FAILED**.
   - **RETRY**: 같은 스테이지를 새 순서로 다시 도전 (점수 유지)
   - **메인화면**: 처음으로 돌아가 스테이지·점수 초기화

| 항목 | 공식 |
|---|---|
| 제한시간 | 5 + 버튼 개수 × 2 (초) |
| 획득 점수 | 1 + 남은 시간 (소수점 버림) |

### 별의 색상과 음계 (왼쪽 → 오른쪽)

| 번호 | 색상 | 음계 |
|---|---|---|
| 1 | 빨강 | 도 (C4) |
| 2 | 주황 | 레 (D4) |
| 3 | 노랑 | 미 (E4) |
| 4 | 초록 | 파 (F4) |
| 5 | 파랑 | 솔 (G4) |
| 6 | 남색 | 라 (A4) |
| 7 | 보라 | 시 (B4) |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조: 왼쪽 정보(Stage/Time/Score), 별자리 보드, START 버튼, 안내 문구, 실패 창 |
| `style.css` | 검정 배경, 원형 버튼, 빛나는 효과. 보드 비율을 고정해 창 크기가 바뀌어도 북두칠성 모양 유지 |
| `game.js` | 게임 로직: 상태 관리, 시연, 입력 판정, 타이머, 점수, 소리(Web Audio API) |

외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 만들었습니다.

### 게임 상태

| 상태 | 의미 | 플레이어 입력 |
|---|---|---|
| READY | 시작 화면 | 불가 |
| COMPUTER_TURN | 컴퓨터 시연 중 | 불가 |
| PLAYER_TURN | 플레이어 입력 대기 | 가능 |
| STAGE_CLEAR | 스테이지 클리어 | 불가 |
| FAILED | 실패 | 불가 |

상태가 바뀔 때마다 이전 상태에서 예약된 시연·전환이 실행되지 않도록 막고, 타이머는 실제 경과시간(`performance.now()`) 기준으로 계산합니다.

## 테스트 결과

Chrome에서 확인한 항목:

- START → Stage 1 시작, 시연 중 클릭 무시
- 시연이 끝난 뒤에 제한시간 시작 (Stage 1: 7초, Stage 2: 9초)
- 정답 입력 시 STAGE CLEAR, 점수 정상 계산, 1.5초 후 다음 스테이지
- 같은 별이 연속으로 나오는 순서도 정상 판정
- 틀린 별 클릭 시 즉시 FAILED, 점수 추가 없음
- 시간 초과 시 FAILED, 이후 클릭 차단
- RETRY 시 스테이지·점수 유지 / 메인화면 시 모두 초기화

## 남은 문제

- 7개 음이 귀로 잘 구별되는지는 직접 들어보며 확인하지 않았습니다.
- Whale 브라우저에서는 아직 테스트하지 않았습니다.
- 아주 좁은 세로 화면에서는 왼쪽 정보 글자가 별과 가까워질 수 있습니다.
